# main 구조

## 개요

메인 프로세스(`/src/main/`)는 Electron 애플리케이션의 백엔드 역할을 수행하며, 데이터 관리, 비즈니스 로직 처리, IPC 통신을 담당합니다.
각 모듈은 명확한 책임과 의존성 규칙을 가지고 있어 코드의 응집도를 높이고 결합도를 낮춥니다.

## 구조

```
src/main/
├── index.ts        # 애플리케이션 진입점
├── repo/           # 데이터 저장소 모듈
├── model/          # 도메인 모델 & 비즈니스 로직
├── ipc/            # IPC 통신 관리
├── window/         # 창 관리
└── common/         # 공통 코드
```

### 구성요소

#### index.ts

- 애플리케이션의 진입점으로, Electron 앱을 초기화하고 메인 창을 생성
- window와 ipc를 import하여 사용 가능

#### repo

- 데이터 저장소 관련 작업(파일 시스템, SQLite 캐시)을 관리
- common를 import하여 사용 가능

#### model

- 도메인 모델의 데이터 구조와 비즈니스 로직이 위치
- repo와 common를 import하여 사용 가능

#### ipc

- 메인 프로세스와 렌더러 프로세스 간의 IPC 통신을 관리
- model와 common를 import하여 사용 가능

#### window

- 애플리케이션 창의 생성과 관리를 담당
- common를 import하여 사용 가능

#### common

- 재사용 가능한 순수한 공통 코드
- 특정 도메인에 종속되지 않음
- 다른 모듈의 코드를 import할 수 없음
