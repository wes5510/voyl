# Product Requirements Document

## 1. 개요

### 제품 목적

Voyl은 누구나 자유롭게 일할 수 있는 유연한 도구로, 개인의 생산성을 극대화하는 것을 목표로 합니다.

### 배경

기존 생산성 도구의 복잡성과 접근성 문제를 해결하기 위해 개발되었습니다. 로그인 없이 즉시 사용 가능하며, 오프라인에서도 동작하는 점이 핵심 특징입니다.

## 2. 범위

### 포함 범위

- Node 관리 (태스크, 폴더, 노트 등)
- 속성 관리 (마감일, 태그 등 사용자 정의 속성)
- 트리 뷰 (계층 구조 표시)
- 태스크 관리 (마감일 설정, 완료 체크)
- 간단한 검색 기능
- 오프라인 사용성
- 계정 없이 사용 가능

### 제외 범위

- 고급 뷰 (리스트, 캘린더 등)
- 작업 자동화 (예: 템플릿 기반 태스크 생성)
- 인박스 등은 초기 버전에서 제외됩니다.

## 3. 기능 요구 사항

아래 표는 Voyl의 주요 기능을 사용자 스토리와 함께 정리한 내용입니다.

| **기능**            | **설명**                                                            | **사용자 스토리**                              | **우선순위** | **기술 요구 사항**                |
| ------------------- | ------------------------------------------------------------------- | ---------------------------------------------- | ------------ | --------------------------------- |
| **Node 관리**       | Node 생성, 삭제, 수정, 이동. Node는 태스크, 폴더, 노트 등을 포함.   | "작업을 계층적으로 정리하고 싶다."             | 높음         | 트리 데이터 구조 구현             |
| **속성 관리**       | 사용자 정의 속성 추가 (예: 마감일, 태그). 그룹화 및 뱃지로 UI 표시. | "Node에 필요한 속성을 추가해 관리하고 싶다."   | 중간         | 유연한 속성 스키마 구현           |
| **트리 뷰**         | 계층적 트리 구조로 Node 표시, 펼치기/접기 가능.                     | "트리 뷰로 Node 구조를 한눈에 파악하고 싶다."  | 높음         | 효율적인 트리 뷰 UI 컴포넌트 구현 |
| **태스크 관리**     | 'task' Node에 마감일 설정 및 완료 체크.                             | "태스크의 마감일과 완료 여부를 관리하고 싶다." | 높음         | 날짜 처리 및 상태 관리            |
| **검색**            | 키워드 기반 Node 검색.                                              | "키워드로 Node를 빠르게 찾고 싶다."            | 중간         | 효율적인 검색 기능 구현           |
| **오프라인 사용성** | 인터넷 없이 로컬 저장소로 사용 가능.                                | "인터넷 없이도 Voyl을 사용하고 싶다."          | 높음         | 로컬 저장소 솔루션 (SQLite 등)    |
| **계정 없이 사용**  | 계정 생성 없이 즉시 사용 가능.                                      | "가입 없이 바로 사용하고 싶다."                | 높음         | 로컬 데이터 저장 및 관리          |

### 추가 세부 사항

### Node 편집

- 제목 편집 시 Backspace로 삭제, Enter로 새 Node 생성.

### 속성 UI

- 속성은 그룹화되어 뱃지 형태로 표시.

## 5. 비기능 요구 사항

### 성능

- 많은 Node를 처리하더라도 빠른 응답성 유지.

### 보안

- 로컬 데이터는 안전하게 저장.

### 접근성

- 계정 없이 사용 가능, 오프라인에서도 동작.

### 사용성

- 직관적이고 간단한 UI/UX 제공.

## 6. 기술 아키텍처

### 프론트엔드

- React (웹), Electron (데스크탑), React Native (모바일)

- Zustand

### 아이콘

- Lucide

### 백엔드

- Node.js (필요 시)

### 데이터베이스

- SQLite3

- Drizzle ORM (better-sqlite3 드라이버)
