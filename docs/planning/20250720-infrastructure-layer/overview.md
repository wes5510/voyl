## 🏗️ 전체 아키텍처

### 경로 구조 설계

```
# 로컬 앱 데이터
## 영구 데이터 (userData)
~/Library/Application Support/voyl/  (macOS 기준)
└── config.json                       # 앱 설정 (workspacePath 포함)

## 캐시 데이터 (cache)
~/Library/Caches/voyl/               (macOS 기준)
└── cache.db                          # SQLite 캐시 (매번 초기화)

# 사용자 워크스페이스 (사용자 지정 경로)
[사용자 지정 워크스페이스]/
├── nodes/                            # 노드 메타데이터 (향후 추가)
├── content/                          # 긴 본문 파일 (향후 추가)
├── log/                              # 변경 이력 (향후 추가)
└── settings.json                     # 워크스페이스 설정
```

### 함수 책임 분리

```typescript
// 앱 수준 경로 (common/paths)
getCachePath() // ~/Library/.../voyl/cache.db
getConfigPath() // ~/Library/.../voyl/config.json
getWorkspacePath() // 사용자 지정 경로

// 워크스페이스 수준 경로 (models/workspace)
getNodesPath() // [workspace]/nodes/
getContentPath() // [workspace]/content/
getLogPath() // [workspace]/log/
```

### 데이터 흐름

```
첫 실행 시:
App 시작 → 설정 확인 → 없음 감지 → 저장 위치 선택 UI →
경로 검증 → 워크스페이스 초기화 → 설정 저장 → 메인 화면

기존 사용자:
App 시작 → 설정 확인 → 있음 감지 → 워크스페이스 검증 → 메인 화면
```
