## 🔄 앱 시작 플로우

### 첫 실행
1. 앱 시작 → IPC 핸들러 등록
2. 프론트엔드 → `isInitialized()` 호출 → false
3. `StorageLocationDialog` 표시
4. 사용자 경로 선택 → `initializeApp(path)`
5. 워크스페이스 생성 → 설정 저장
6. DB 초기화 → 메인 화면 진입

### 기존 사용자
1. 앱 시작 → IPC 핸들러 등록
2. 프론트엔드 → `isInitialized()` 호출 → true
3. `loadApp()` 호출 → DB 초기화
4. 메인 화면 직접 진입
