### **2. 경로 관리 함수** (`src/main/common/paths/index.ts`)

**설계 원칙**: 앱 수준만 담당, 최소 필요 함수만 구현

```typescript
import { app } from 'electron'
import { join } from 'path'
import fs from 'fs-extra'
import { PATHS } from './const.js'

// 1. 로컬 앱 설정 경로
export function getConfigPath(): string {
  return join(app.getPath('userData'), PATHS.LOCAL.CONFIG_FILE)
  // → ~/Library/Application Support/voyl/config.json
}

// 2. SQLite 캐시 경로
export function getCachePath(): string {
  return join(app.getPath('userData'), PATHS.LOCAL.CACHE_FILE)
  // → ~/Library/Application Support/voyl/cache.db
}

// 3. 사용자 워크스페이스 경로 (config.json에서 로드)
export function getWorkspacePath(): string {
  const configPath = getConfigPath()
  if (!fs.existsSync(configPath)) {
    throw new Error('App configuration not found. Initialization required.')
  }
  const config = fs.readJsonSync(configPath)
  if (!config.workspacePath) {
    throw new Error('Workspace path not configured.')
  }
  return config.workspacePath
}

// 4. 워크스페이스 설정 파일 경로
export function getWorkspaceSettingsPath(): string {
  return join(getWorkspacePath(), PATHS.WORKSPACE.SETTINGS_FILE)
  // → [workspace]/settings.json
}

// 5. 앱 설정 존재 여부 확인
export function hasConfig(): boolean {
  return fs.existsSync(getConfigPath())
}
```

## ⚙️ 구현 세부사항

### **데이터베이스 파일명 변경**

- **기존**: `database.sqlite`
- **변경**: `cache.db`
- **이유**: 의미적 명확성 (캐시 용도임을 명시)
- **마이그레이션**: 불필요 (새 파일로 시작)

- **기존**: 개발 시 `app.getAppPath()`, 프로덕션 시 `userData`
- **변경**: 모든 환경에서 `userData` 사용
- **이유**: 일관성, 단순성

- **Config 없음**: UI 트리거용 에러 (사용자 액션 필요)
