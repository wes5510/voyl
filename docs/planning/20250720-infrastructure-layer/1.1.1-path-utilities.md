**설계 원칙**: 계층적 구조로 앱과 워크스페이스 관리, ESLint 규칙 준수

#### **앱 상수 정의** (`const.ts`)

```typescript
/**
 * 앱 레벨 경로 상수 (캡슐화됨)
 * 외부에서 직접 접근 불가, 경로 함수를 통해서만 사용

const APP_PATHS = {
  CONFIG_FILE: 'config.json', // 앱 설정 (workspacePath 포함)
  CACHE_FILE: 'cache.db', // SQLite 캐시 (기존 database.sqlite에서 변경)
} as const

export { APP_PATHS }
```

#### **앱 통합 인터페이스** (`index.ts`)

```typescript
import { app } from 'electron'
import { join } from 'path'
import fs from 'fs-extra'
import { APP_PATHS } from './const.js'

/**
 * 앱 설정 파일 경로
 * @returns ~/Library/Application Support/voyl/config.json
 */
export function getConfigPath(): string {
  return join(app.getPath('userData'), APP_PATHS.CONFIG_FILE)
}

/**
 * SQLite 캐시 데이터베이스 경로
 * @returns ~/Library/Caches/voyl/cache.db (캐시 전용 디렉터리)
 */
export function getCachePath(): string {
  return join(app.getPath('cache'), APP_PATHS.CACHE_FILE)
}

/**
 * 앱 초기화 상태 확인
 * 비동기로 통일하여 일관성 유지
 */
export async function isInitialized(): Promise<boolean> {
  return fs.existsSync(getConfigPath())
}

/**
 * 앱 설정 로드
 */
export async function loadAppConfig(): Promise<{ workspacePath: string }> {
  const configPath = getConfigPath()
  if (!fs.existsSync(configPath)) {
    throw new Error('App configuration not found. Initialization required.')
  }
  const config = await fs.readJson(configPath)
  if (!config.workspacePath) {
    throw new Error('Workspace path not configured.')
  }
  return config
}

// 워크스페이스 인터페이스를 통해 재export (캡슐화 유지)
export * from './workspace/index.js'

// 향후 앱 초기화 함수 (1.1.2에서 구현)
// export { initializeApp } from './initialization.js'
```

- `export *`를 통한 하위 모델 재export

**설계 원칙**: 앱의 하위 모델로 워크스페이스 관리, ESLint 규칙 준수

#### **워크스페이스 상수 정의** (`const.ts`)

```typescript
/**
 * 워크스페이스 레벨 경로 상수 (캡슐화됨)

  CONTENT_DIR: 'content', // 긴 본문 파일 (향후)
```

#### **워크스페이스 통합 인터페이스** (`index.ts`)

```typescript
import { join } from 'path'
import { loadAppConfig } from '../index.js' // ✅ 같은 model 내 import
import { WORKSPACE_PATHS } from './const.js'

/**
 * 사용자 워크스페이스 루트 경로
 * 앱 설정에서 로드
 */
export async function getWorkspacePath(): Promise<string> {
  const config = await loadAppConfig()
  return config.workspacePath
}

/**
 * 워크스페이스 설정 파일 경로
 * @returns [workspace]/settings.json
 */
export async function getWorkspaceSettingsPath(): Promise<string> {
  const workspacePath = await getWorkspacePath()
  return join(workspacePath, WORKSPACE_PATHS.SETTINGS_FILE)
}

/**
 * 노드 메타데이터 디렉터리 경로
 * @returns [workspace]/nodes
 */
export async function getNodesPath(): Promise<string> {
  const workspacePath = await getWorkspacePath()
  return join(workspacePath, WORKSPACE_PATHS.NODES_DIR)
}

/**
 * 콘텐츠 파일 디렉터리 경로
 * @returns [workspace]/content
 */
export async function getContentPath(): Promise<string> {
  const workspacePath = await getWorkspacePath()
  return join(workspacePath, WORKSPACE_PATHS.CONTENT_DIR)
}

/**
 * 로그 파일 디렉터리 경로
 * @returns [workspace]/log
 */
export async function getLogPath(): Promise<string> {
  const workspacePath = await getWorkspacePath()
  return join(workspacePath, WORKSPACE_PATHS.LOG_DIR)
}

// 향후 1.1.2에서 구현

  // 워크스페이스 초기화 로직
```

## 🏗️ 파일 구조

```
src/main/models/app/
├── const.ts              # 앱 레벨 상수 (CONFIG_FILE, CACHE_FILE)
├── index.ts              # 앱 통합 인터페이스 (함수 구현 + 워크스페이스 재export)
└── workspace/            # 워크스페이스 하위 모델
    ├── const.ts          # 워크스페이스 레벨 상수 (SETTINGS_FILE, NODES_DIR...)
    └── index.ts          # 워크스페이스 통합 인터페이스 (함수 구현 + 초기화)

// common/paths/ 디렉터리는 제거됨
// paths.ts 파일들 제거 (index.ts로 통합)
```

**단순화된 구조 원칙**:

- **models/app**: 앱 최상위 도메인 (설정, 캐시, 생명주기)
- **models/app/workspace**: 앱 하위 모델 (워크스페이스 내부 구조)
- **index.ts 통합**: 함수 구현과 인터페이스를 하나의 파일에서 관리
- **2파일 구조**: 각 레벨에서 const.ts + index.ts만 사용
- **ESLint 규칙 준수**: 같은 model 내에서만 import

### **앱 도메인 테스트** (`src/main/models/app/index.test.ts`)

```typescript
import { jest } from '@jest/globals'
import fs from 'fs-extra'
import { getConfigPath, getCachePath, hasConfig, loadAppConfig } from './index.js'

describe('App Functions', () => {
  describe('getConfigPath', () => {
    it('should return correct config path', () => {
      const path = getConfigPath()
      expect(path).toContain('config.json')
      expect(path).toContain('userData')
    })
  })

  describe('getCachePath', () => {
    it('should return correct cache path', () => {
      const path = getCachePath()
      expect(path).toContain('cache.db')
      expect(path).toContain('userData')
    })
  })

  describe('hasConfig', () => {
    it('should return false when config not exists', () => {
      jest.spyOn(fs, 'existsSync').mockReturnValue(false)
      expect(hasConfig()).toBe(false)
    })

    it('should return true when config exists', () => {
      jest.spyOn(fs, 'existsSync').mockReturnValue(true)
      expect(hasConfig()).toBe(true)
    })
  })

  describe('loadAppConfig', () => {
    it('should load valid config', async () => {
      jest.spyOn(fs, 'existsSync').mockReturnValue(true)
      jest.spyOn(fs, 'readJson').mockResolvedValue({ workspacePath: '/test/workspace' })

      const config = await loadAppConfig()
      expect(config.workspacePath).toBe('/test/workspace')
    })

    it('should throw when config not found', async () => {
      jest.spyOn(fs, 'existsSync').mockReturnValue(false)

      await expect(loadAppConfig()).rejects.toThrow('App configuration not found')
    })
  })
})
```

## ⚙️ 구현 세부사항

### **계층적 구조 원칙**

- **앱 최상위**: 앱 전역 설정, 캐시, 메타데이터
- **워크스페이스 하위**: 사용자 콘텐츠, 프로젝트별 설정
- **의존성 방향**: workspace → app (상위 접근만 허용)
- **캡슐화**: 각 레벨의 상수는 외부 접근 불가
- **통제된 인터페이스**: models/app/index.ts에서만 외부 노출

### **데이터베이스 파일명 변경**

- **기존**: `database.sqlite`
- **변경**: `cache.db`
- **이유**: 의미적 명확성 (캐시 용도임을 명시)
- **위치**: 앱 도메인 (userData 디렉터리)

### **비동기 함수 설계**

- **워크스페이스 경로**: 모두 비동기 (설정 파일 로드 필요)
- **앱 경로**: 동기 함수 (직접 계산 가능)
- **일관성**: 도메인 내에서 통일된 패턴

### **에러 처리 전략**

- **Config 없음**: UI 트리거용 에러 (사용자 액션 필요)
- **권한 문제**: 시스템 에러 (앱 중단)
- **워크스페이스 설정 오류**: 워크스페이스 재선택 유도
- **메시지**: 영어, 개발자 친화적
