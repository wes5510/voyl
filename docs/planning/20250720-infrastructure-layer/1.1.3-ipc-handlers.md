### **2. 앱 IPC 핸들러 구현** (`src/main/ipc/app.ts`)

**목표**: 모든 앱 관련 핸들러를 하나의 파일에 구현

```typescript
// src/main/ipc/app.ts
import { dialog } from 'electron'
import { homedir } from 'os'
import { join } from 'path'
import { initializeApp, loadApp, isInitialized } from '../models/app/index.js'
import { APP_CHANNELS } from '../common/channel.const.js'

/**
 * 디렉터리 선택 다이얼로그 (Documents 초기 경로)
 */
async function openDirectoryDialog(): Promise<string | null> {
  const result = await dialog.showOpenDialog({
    properties: ['openDirectory', 'createDirectory'],
    title: 'Select Workspace Location',
    buttonLabel: 'Select',
    defaultPath: join(homedir(), 'Documents'),
  })

  if (result.canceled || result.filePaths.length === 0) {
    return null
  }

  return result.filePaths[0]
}

/**
 * 앱 초기화 상태 확인
 */
async function checkIsInitialized(): Promise<boolean> {
  try {
    return isInitialized()
  } catch (error) {
    console.error('Failed to check initialization status:', error)
    return false
  }
}

/**
 * 사용자 선택 경로로 앱 초기화 (첫 실행)
 */
async function handleInitializeApp(workspacePath: string): Promise<void> {
  try {
    await initializeApp(workspacePath)
  } catch (error) {
    throw new Error(error.message || 'Failed to initialize app')
  }
}

/**
 * 앱 로드 (일반 실행)
 */
async function handleLoadApp(): Promise<void> {
  try {
    await loadApp()
  } catch (error) {
    throw new Error(error.message || 'Failed to load app')
  }
}
```

### **3. 핸들러 등록**

```typescript
// src/main/ipc/app.ts (계속)
import { IpcMain } from 'electron'

export default function appHandlers(ipcMain: IpcMain) {
  // 앱 초기화 상태 확인
  ipcMain.handle(APP_CHANNELS.IS_INITIALIZED, checkIsInitialized)

  // 워크스페이스 경로 선택
  ipcMain.handle(APP_CHANNELS.SELECT_WORKSPACE_PATH, openDirectoryDialog)
  
  // 앱 초기화 (첫 실행)
  ipcMain.handle(APP_CHANNELS.INITIALIZE_APP, (_, workspacePath: string) =>
    handleInitializeApp(workspacePath),
  )
  
  // 앱 로드 (일반 실행)
  ipcMain.handle(APP_CHANNELS.LOAD_APP, handleLoadApp)
}
```

```typescript
// src/main/ipc/index.ts에 추가
import appHandlers from './app.js'

appHandlers(ipcMain)
```

## 🧪 테스트 계획

### **통합 테스트** (`src/main/ipc/app.test.ts`)

```typescript
describe('App IPC Handlers', () => {
  describe('checkIsInitialized', () => {
    it('should return true when app is initialized', async () => {
      const result = await checkIsInitialized()
      expect(typeof result).toBe('boolean')
    })

    it('should return false on error', async () => {
      const result = await checkIsInitialized()
      expect(result).toBe(false)
    })
  })
  
  describe('openDirectoryDialog', () => {
    it('should open dialog with Documents default path', async () => {
      const result = await openDirectoryDialog()
      // Result can be null if user cancels
      expect(result === null || typeof result === 'string').toBe(true)
    })
  })

  describe('handleInitializeApp', () => {
    it('should initialize app successfully', async () => {
      const testPath = '/tmp/test-workspace'
      await expect(handleInitializeApp(testPath)).resolves.not.toThrow()
    })
    
    it('should throw error for invalid path', async () => {
      const invalidPath = '/invalid/path'
      await expect(handleInitializeApp(invalidPath)).rejects.toThrow()
    })
  })
  
  describe('handleLoadApp', () => {
    it('should load app successfully', async () => {
      await expect(handleLoadApp()).resolves.not.toThrow()
    })
    
    it('should throw error when config missing', async () => {
      // Mock missing config scenario
      await expect(handleLoadApp()).rejects.toThrow()
    })
  })
})
```

## ⚙️ 에러 처리 전략

### **에러 분류**

- **사용자 에러**: 잘못된 경로 선택, 권한 없음
- **시스템 에러**: 디스크 공간 부족, 네트워크 문제
- **프로그래밍 에러**: IPC 통신 실패, 타입 오류

### **복구 전략**

- **자동 재시도**: 네트워크 관련 오류
- **사용자 선택**: 경로 문제 시 다시 선택 유도
- **앱 종료**: 치명적 시스템 오류
