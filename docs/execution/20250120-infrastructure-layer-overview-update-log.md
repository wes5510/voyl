상세 계획에 맞춰 개요 문서의 **1. 인프라 레이어 구현** 섹션을 업데이트

## 📝 수행 작업

### **대상 파일**

- `docs/planning/20250720-backend-data-storage-migration.md`

### **변경 내용**

#### **1. 목표 명확화**

```diff
- **목표**: Repository 패턴 기반 인프라 구축
+ **목표**: 워크스페이스 경로 관리 및 초기화 인프라 구축
```

#### **2. 구현 내용 세분화**

```diff
- - 폴더 구조 생성 (백엔드)
- - 저장 위치 선택 UI (프론트엔드)
- - IPC 연결
- - 경로 관리 유틸리티
- - 초기화 프로세스
+ - **경로 관리**: 앱 데이터와 워크스페이스 분리된 2-tier 구조
+ - **워크스페이스 초기화**: 폴더 생성, 권한 검증, 에러 처리
+ - **IPC 통신**: 백엔드-프론트엔드 워크스페이스 관리 API
+ - **저장 위치 선택 UI**: 직관적인 사용자 경험
+ - **앱 시작 통합**: 첫 실행 vs 기존 사용자 플로우
```

#### **3. 완료 기준 정확화**

```diff
- **완료 기준**: 사용자가 저장 위치를 선택하고 .voyl 폴더가 생성됨
+ **완료 기준**: 사용자가 워크스페이스 경로를 지정하고 폴더가 생성됨
```
